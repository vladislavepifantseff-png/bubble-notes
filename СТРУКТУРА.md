# Заметки Бабл — договорённости

Альтернатива заметкам в телефоне: идеи по проектам не теряются в общей ленте, а живут в пузырях.

## Платформа
- PWA на iPhone, пока только для одного пользователя.
- Данные хранятся только на телефоне (без сервера и логина). Обязателен экспорт/импорт в файл для бэкапа.

## Структура
```
Пространства («Проекты», «Контент», …) — свайп между экранами
 └─ Пузыри-проекты — размер = количество активных записей
     ├─ Ветки (один уровень; добавить / переименовать / удалить)
     │   ├─ Записи: текст, ссылки, фото/скриншоты
     │   └─ «Выполнено» — отдельный список
     └─ Пузырь: в архив / удалить
```
- Пузырь «Входящие» — для записей, сделанных без выбора места.
- У каждого пузыря автоматически есть ветка «Разное» — туда падает запись, если выбран пузырь, но не ветка.
- Архив — отдельный экран для заархивированных пузырей.

## Главный экран
- Мыльные 3D-пузыри (прозрачные, переливаются).
- Пузырь можно зажать и таскать — остальные пружинят, сжимаются, отскакивают.
- Тап по пузырю — остальные исчезают, он встаёт по центру, из него выезжают ветки.
- Кнопка «+» — быстрая запись: текст (голос — через диктовку клавиатуры iOS), фото, ссылка → выбор пузыря (необязательно).

## Внутри ветки
- Список записей: отметить выполненным, удалить, перетащить (изменить порядок).
- «Главный шаг»: строку можно выделить — рисованная карандашная рамка + карандашный восклицательный знак.

## Решения после макета
- Поиск по всем записям — кнопка справа внизу на главном экране (этап 2).
- На пузыре «Входящие» — счётчик новых записей.
- Пузырь-проект создаётся кнопкой слева внизу на главном экране.
- Тап по активной вкладке пространства — переименовать / удалить пространство.
- Во «Входящих» записи разбираются свайпом влево → «Перенести».
- «Перенести» внутри пузыря: сначала ветки этого пузыря, «＋ Новая ветка», «В другой пузырь…». При выборе пузыря всегда спрашиваем ветку (можно создать новую).
- Пузырь можно перенести в другое пространство: меню «⋯» открытого пузыря.
- Уведомление о действии — маленькая тёмная «таблетка»: на главном экране в свободной полосе под вкладками (пузыри туда не заходят), в ветке — над первой записью. Не перехватывает нажатия.
- Пузыри касаются мягко: без отскоков и вздрагиваний, плавно поджимаются.

## Решения этапа 2 (без макета — по просьбе «делай всё по порядку»)
- Фото: кнопка-камера слева от строки ввода в ветке и в окне «+». Можно несколько фото, можно запись только из фото. Сжатие до 1600 px (JPEG). Тап по миниатюре — просмотр на весь экран, листать вбок, «Удалить фото».
- Архив: «⋯» открытого пузыря → «В архив». Вход в архив — кнопка «архив · N» под вкладками или тап по активной вкладке → «Архив». В архиве: вернуть или удалить навсегда. Архив — у каждого пространства свой.
- Поиск: кнопка справа внизу. Ищет по тексту всех записей во всех пространствах, включая выполненные и архив; «ё» = «е». Тап по результату открывает ветку и подсвечивает запись, «Назад» — к результатам.
- Резервная копия: тап по активной вкладке → «Резервная копия» → «Сохранить копию в файл» (через «Поделиться» → «Сохранить в Файлы») или «Восстановить из файла…» (заменяет всё, перед этим показывает, что в файле). Видна дата последней копии.

## Этапы
1. ✅ Пузыри с физикой, открытие пузыря и ветки, записи, главный шаг, хранение на телефоне. Проверено на iPhone, правки по первому отзыву внесены.
2. ✅ Фото и скриншоты, архив пузырей, поиск, экспорт/импорт. Проверено в headless Chrome, на iPhone — ждёт проверки.
3. Ярлык в «Командах» для записи в одно касание, шлифовка по впечатлениям.

## Осознанно НЕ делаем
- «Пыль» / потускнение забытых пузырей — маленький пузырь сам по себе сигнал, что про проект забыли.
- Подветки.

## Ограничения iOS (учесть)
- PWA нельзя добавить в меню «Поделиться» — скриншоты/ссылки добавляются изнутри приложения.
- Нет виджета; быстрый вход — через «Команды» (кнопка действия / тап по спинке) с открытием сразу в режиме записи.
- Нет вибрации (хаптиков) в PWA.
