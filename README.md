# Заметки Бабл

Заметки-пузыри для iPhone: каждый проект — мыльный пузырь, который растёт вместе с числом идей.
Приложение работает в браузере и ставится на экран «Домой» как обычное (PWA). Все записи хранятся только в телефоне.

## Установка на iPhone
1. Открой ссылку на приложение в **Safari**.
2. Нажми «Поделиться» → **«На экран „Домой“»**.
3. Запускай с иконки: так приложение открывается на весь экран и работает без интернета.

## Как устроено
- `index.html`, `css/app.css` — разметка и стили.
- `js/physics.js` — пузыри: притяжение к центру, столкновения, перетаскивание, упругая деформация.
- `js/main.js` — экраны пространства и открытого пузыря.
- `js/list.js` — экран ветки: записи, «выполнено», главный шаг, свайп, перетаскивание.
- `js/store.js` — хранение в IndexedDB на устройстве.
- `sw.js` — офлайн-кэш. Новая версия подтягивается в фоне и появляется со следующего запуска. **При каждом выпуске поднимай `CACHE` (`bubble-notes-vN`).**
- `scripts/make-icons.mjs` — генерирует иконки: `node scripts/make-icons.mjs`.

Сборка не нужна: это статические файлы. Локальный запуск — `python3 -m http.server 8765`, затем открыть `http://localhost:8765`.

## Опубликовано
GitHub Pages из ветки `main`: https://vladislavepifantseff-png.github.io/bubble-notes/ — `git push` → сайт обновляется примерно за минуту.
На iPhone новая версия появляется после открытия приложения и повторного запуска (смахнуть из переключателя).

## Проверки (headless Chrome)
Нужен Google Chrome и Node. Сервер: `python3 -m http.server 8765` в корне проекта. Затем:
```
cd tests && npm install
node scenarios.mjs out          # перенос записей и пузырей, уведомление — ✓/✗ по пунктам
node jitter.mjs out 60 drag     # плавность при перетаскивании (ориентиры — в начале файла)
node jitter.mjs out 120 rest    # плавность на экране 120 Гц
```
